# NOVA

A Python voice assistant, built before LLM tools were common, that runs everyday tasks from spoken commands. Fully rule-based, with no AI models.

- Voice commands to send email and WhatsApp messages and to control Spotify playback
- Controls lights and devices through my SmartLiving home automation system
- Amazon price-monitoring scraper that sends automatic Discord alerts
- Location-based weather warnings

**Tech:** Python, Google speech recognition, web scraping, Discord, WhatsApp and email automation
